## 🛠️ What I'm Building

### 🥊 [My Holistic Muay Thai Journey](https://myholisticmuaythaijourney.com/) *(Fully Built & Deployed)*
*Full-spectrum Muay Thai training & lifestyle system (iOS & Android)*
* **Production Mobile Platform:** Built on **35 years of training and teaching** as a Kru-qualified coach.
* **Voice Session Logging & Kru AI Coach:** Converts unstructured voice input into structured athletic performance data and AI coaching feedback.
* **Smart Load Management:** Features dynamic Strength & Conditioning programming shaped by daily training load (ASCA-aligned rules).
* Includes meditation, breathwork, and recovery protocols built specifically for high-impact combat athletes.

### 🎙️ [Oracle SpeakFlow](https://github.com/DifTorHeSmushma/oracle-speakflow)
*Fast, hands-free speech-to-text into whatever app has focus (Open Source — Windows / macOS / Linux)*
* **Architecture:** Hybrid local/cloud pipeline using Silero VAD (ONNX), Groq API, and bundled local Whisper sidecars.
* **Resilience:** Focus-guard fallback to clipboard, full-width OS physical mute kill-switch, deterministic jargon correction dictionary.
* **Engineering Standard:** 170+ unit and UI tests, automated cross-platform CI/CD package runners.
